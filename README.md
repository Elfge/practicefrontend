# 408考研题库系统 - 前端

基于Vue 3 + Element Plus构建的408考研题库管理系统前端界面。

## 功能模块

### 1. 用户认证模块
- **登录功能**：支持用户名/邮箱登录，管理员/普通用户角色区分
- **注册功能**：用户注册，包含考试日期设置
- **记住我功能**：延长登录状态
- **路由守卫**：未登录用户自动跳转到登录页
- **权限控制**：管理员专属页面访问控制

### 2. 首页模块
- **数据统计卡片**：展示总题数、已完成题数、正确率、备考天数
- **学习进度**：各科目学习进度可视化展示
- **正确率趋势图**：使用ECharts展示学习效果
- **快速操作**：开始刷题、模拟考试、错题本、笔记收藏
- **今日任务**：待完成的学习任务清单

### 3. 个人中心模块
- **个人信息展示**：用户名、邮箱、注册时间、考试日期
- **学习计划制定**：设置每日刷题目标、考试日期
- **学习数据统计**：
  - 总刷题量、平均正确率统计
  - 各科目学习进度柱状图
  - 薄弱环节分析（按错误率排序）
  - 学习时长统计（今日/本周/累计）
- **针对练习**：根据薄弱环节推荐相关题目

### 4. 练习模块
- **多种练习模式**：
  - 顺序练习：按题目顺序逐题练习
  - 随机练习：随机抽取题目
  - 专项练习：按科目/章节/题型筛选练习
- **答题功能**：
  - 实时答题反馈
  - 答案解析展示
  - 收藏/笔记快捷操作
  - 上一题/下一题切换
- **答题历史**：记录答题状态和结果

### 5. 错题本模块
- **错题管理**：
  - 查看所有错题
  - 按科目/题型筛选错题
  - 错题重做功能
  - 移出错题本
- **错题统计**：各科目错误率分析

### 6. 笔记模块
- **笔记管理**：
  - 添加/编辑/删除笔记
  - 按题目关联笔记
  - 笔记搜索功能
- **笔记分类**：按科目/章节组织

### 7. 收藏模块
- **收藏管理**：
  - 收藏题目
  - 查看收藏列表
  - 取消收藏
- **收藏分类**：按科目/题型分组

### 8. 任务模块
- **任务管理**：
  - 创建学习任务
  - 任务进度跟踪
  - 任务完成提醒
- **任务统计**：每日/每周任务完成情况

### 9. 模拟考试模块
- **考试列表**：
  - 查看可参加的模拟考试
  - 考试信息展示（时长、题量、分值）
- **参加考试**：
  - 计时功能
  - 答题卡导航
  - 标记题目功能
  - 自动保存答案
- **考试结果**：
  - 成绩统计
  - 答题详情查看
  - 成绩分析
- **试卷复习**：
  - 查看完整试卷
  - 答案解析
  - 错题标记

### 10. 题库管理模块（管理员）
- **多维度筛选**：
  - 科目筛选（数据结构/计算机组成原理/操作系统/计算机网络）
  - 章节筛选
  - 题型筛选（单选/多选/填空/综合题）
  - 难度筛选（基础/中等/困难）
  - 年份筛选（1998-2025年）
- **题目管理功能**：
  - 查看题目详情
  - 添加新题目
  - 编辑现有题目
  - 删除题目
  - 批量导入
- **视图模式**：
  - 列表视图：表格形式展示题目
  - 卡片视图：卡片形式展示题目
- **分页功能**：支持自定义每页显示数量

## 技术栈

- **框架**：Vue 3 (Composition API)
- **UI组件库**：Element Plus
- **路由管理**：Vue Router 4
- **状态管理**：Vuex 4
- **图表库**：ECharts + Vue-ECharts
- **HTTP客户端**：Axios
- **构建工具**：Vue CLI

## 安装和运行

1. 安装依赖
```bash
npm install
```

2. 启动开发服务器
```bash
npm run serve
```

3. 构建生产版本
```bash
npm run build
```

## 特色功能

1. **408考纲全覆盖**：支持数据结构、计算机组成原理、操作系统、计算机网络四门科目
2. **智能学习分析**：自动分析薄弱环节，推荐针对性练习
3. **可视化数据展示**：使用图表直观展示学习进度和效果
4. **完整的模拟考试系统**：
   - 计时答题
   - 答题卡导航
   - 自动交卷
   - 成绩分析
   - 试卷复习
5. **错题本与笔记**：方便复习和知识点整理
6. **任务管理**：自定义学习任务，跟踪学习进度
7. **收藏功能**：收藏重点题目，方便复习
8. **权限管理**：区分普通用户和管理员权限
