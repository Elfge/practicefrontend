# 408考研题库系统 - 前端

基于Vue 3 + Element Plus构建的408考研题库管理系统前端界面。

## 功能模块

### 1. 用户认证模块
- **登录功能**：支持用户名/邮箱登录
- **注册功能**：用户注册，包含考试日期设置
- **记住我功能**：延长登录状态
- **路由守卫**：未登录用户自动跳转到登录页

### 2. 首页模块
- **数据统计卡片**：展示总题数、已完成题数、正确率、备考天数
- **学习进度**：各科目学习进度可视化展示
- **正确率趋势图**：使用ECharts展示学习效果
- **快速操作**：开始刷题、模拟考试、错题本、笔记收藏
- **今日任务**：待完成的学习任务清单

### 3. 个人中心模块
- **个人信息展示**：用户名、邮箱、注册时间、考试日期
- **学习计划制定**：设置每日刷题目标、考试日期
- **学习数据统计**：
  - 总刷题量、平均正确率统计
  - 各科目学习进度柱状图
  - 薄弱环节分析（按错误率排序）
  - 学习时长统计（今日/本周/累计）
- **针对练习**：根据薄弱环节推荐相关题目

### 4. 题库管理模块
- **多维度筛选**：
  - 科目筛选（数据结构/计算机组成原理/操作系统/计算机网络）
  - 章节筛选
  - 题型筛选（单选/多选/填空/综合题）
  - 难度筛选（基础/中等/困难）
  - 年份筛选（1998-2025年）
- **题目管理功能**：
  - 查看题目详情
  - 添加新题目
  - 编辑现有题目
  - 删除题目
  - 批量导入/导出
- **视图模式**：
  - 列表视图：表格形式展示题目
  - 卡片视图：卡片形式展示题目
- **分页功能**：支持自定义每页显示数量

## 技术栈

- **框架**：Vue 3 (Composition API)
- **UI组件库**：Element Plus
- **路由管理**：Vue Router 4
- **状态管理**：Vuex 4
- **图表库**：ECharts + Vue-ECharts
- **HTTP客户端**：Axios
- **构建工具**：Vue CLI

## 安装和运行

1. 安装依赖
```bash
npm install
```

2. 启动开发服务器
```bash
npm run serve
```

3. 构建生产版本
```bash
npm run build
```
